# PMN-004 KONTROL

**投稿事前検問装置**

<img width="702" height="935" alt="image" src="https://github.com/user-attachments/assets/626d9d07-6cab-4ada-9397-bbfaee26827e" />


SNSへ投稿する前に、文章に含まれる「事故りやすい要素」をローカルAIで検査するWindows向けツールです。

KONTROLは文章の面白さ、センス、バズりやすさを評価しません。  
投稿を禁止したり、文章を勝手に修正したりもしません。

## 判定項目

- 怒り
- 攻撃性
- 人格攻撃
- ハンブルブランギング
- 後悔リスク
- 総合投稿リスク

## 特徴

- 完全ローカル処理
- クラウドAI API不要
- API利用料0円
- 投稿文を外部サーバーへ送信しない
- 最大2,000文字
- 文字数カウンター
- 検問中ステータス表示
- 60秒を超えた場合の遅延案内
- 検問中止
- 結果欄のマウスホイールスクロール

## 必要環境

- Windows 10 / 11
- Python 3.10以上
- [Ollama](https://ollama.com/)
- `qwen3:4b`

## セットアップ

Ollamaをインストールしたあと、PowerShellまたはコマンドプロンプトで次を実行します。

```powershell
ollama run qwen3:4b
```

モデルのダウンロードが完了し、チャット画面が開けば準備完了です。終了して構いません。

## 起動

`run_kontrol.bat` をダブルクリックしてください。

または:

```powershell
python kontrol.py
```

## 使い方

1. Xなどで投稿予定文を書く
2. コピーする
3. KONTROLで `CLIPBOARD`
4. `検問開始`
5. 判定結果を確認する
6. 投稿するかどうかは自分で決める

## プライバシー

KONTROLは `127.0.0.1` 上で動作するOllamaだけに接続します。

- 投稿本文を保存しません
- 投稿履歴を保存しません
- テレメトリを送信しません
- OpenAIなどのクラウドAI APIを使用しません
- APIキーは不要です

ただし、Ollama本体やモデルのインストール・更新時の通信については、それぞれのソフトウェアの仕様に従います。

## 判定について

スコアは参考値です。科学的な確率や客観的な人格評価ではありません。

特にハンブルブランギングは文脈依存性が高く、誤判定する場合があります。

KONTROLは投稿者本人の人格を評価するものではなく、入力された文章だけを検査します。

## モデル

標準モデル:

```text
qwen3:4b
```

KONTROLでは分類速度を優先し、Ollama APIの thinking を無効にして利用します。
